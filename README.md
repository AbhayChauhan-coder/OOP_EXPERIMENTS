# OOP_EXPERIMENTS

A collection of C++ practical assignments demonstrating Object-Oriented Programming concepts and their implementation.

## Practical Assignments

1. Data Types, Variables, Constants, Operators and Input/Output
2. Inheritance using Vehicle and Car Classes
3. Constructors, Copy/Move Operations and Destructors
4. Multilevel Inheritance using Person, Student and GraduateStudent
5. Runtime Polymorphism using Abstract Shape Class
6. Function Overloading and Operator Overloading using Complex Numbers
7. Generic Stack and Queue using Templates
8. STL Containers and Algorithms for Student Marks
9. Custom Exception Handling in Banking Transactions
10. CSV File Handling using fstream

## Concepts Covered

- Classes and Objects
- Constructors and Destructors
- Copy and Move Semantics
- Single and Multilevel Inheritance
- Runtime Polymorphism
- Function and Operator Overloading
- Templates
- STL Containers and Algorithms
- Exception Handling
- File Handling

## Technologies Used

- Language: C++
- Standard: C++11 or later
- Compiler: GCC / G++

## How to Open in VS Code

1. Download or clone this repository.
2. Open Visual Studio Code.
3. Select **File → Open Folder**.
4. Select the `OOP_EXPERIMENTS` folder.
5. Install the Microsoft C/C++ extension.
6. Open the C++ file you want to execute.

## How to Compile and Run in VS Code

### Step 1: Open Terminal

Go to **Terminal → New Terminal**.

### Step 2: Check GCC Compiler

```bash
g++ --version
```

### Step 3: Compile a C++ File

Example for Assignment 1:

```bash
g++ -std=c++11 "Assignment 1.cpp" -o assignment1
```

### Step 4: Run the Program

**Linux:**
```bash
./assignment1
```

**Windows:**
```bash
.\assignment1.exe
```

### Running Other Assignments

Change the filename and executable name accordingly.

Example:

```bash
g++ -std=c++11 "Assignment 5.cpp" -o assignment5
./assignment5
```

## Important Notes

- Each assignment is a separate C++ program.
- Every file contains its own `main()` function.
- Compile and run one assignment at a time.
- Do not compile all assignment files together.
- Some programs require user input, while others use predefined sample values.

## Purpose

Created for learning, practicing, and understanding C++ programming and Object-Oriented Programming concepts through practical implementations.
